# 기업 재무 건강검진 Financial Health Reader

일반 사용자가 재무제표를 쉽게 이해할 수 있도록 만든 모바일 대응 Streamlit 웹앱입니다.

## 핵심 기능

- 재무상태표, 손익계산서, 현금흐름표, 자본변동표 분석
- 주석/감사의견 텍스트 특이사항 탐지
- 매출 성장성, 수익성, 안정성, 현금흐름, EPS/PER/PBR 등 핵심 지표 계산
- 일반인용 쉬운 해석
- 좋은 점, 주의할 점, 추가 확인 질문, 종합 결론 제공
- 표 붙여넣기, 엑셀/CSV 업로드, OpenDART 자동 조회 선택 지원
- 회사명 별칭 검색: 예) SK하이닉스, sk hynix, 에스케이하이닉스, 하이닉스, 000660
- 앱처럼 보이도록 모바일 카드형 UI, 큰 버튼, 탭 메뉴, 건강 점수 바 적용
- Streamlit Cloud 배포 후 핸드폰 데이터/외부 와이파이에서도 접속 가능

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## OpenDART 자동 조회

OpenDART API 키를 발급받은 뒤 Streamlit Cloud Secrets에 아래처럼 넣습니다.

```toml
OPENDART_API_KEY = "여기에_발급받은_키"
```

키 없이도 샘플, 표 붙여넣기, 파일 업로드 분석은 가능합니다.

## 법률·규제·저작권 고지

본 앱은 재무정보 이해를 돕는 정보 제공형 도구입니다. 투자자문, 회계감사, 세무자문, 법률자문이 아닙니다. 자동 분석 결과는 원문 공시자료, 감사보고서, 전문가 검토를 대체하지 않습니다.

업로드 파일은 앱 실행 세션에서 분석에만 사용하며, 이 코드에는 파일 저장 기능을 두지 않았습니다. 공시자료 사용 시 출처와 원문 링크를 제공하는 방식으로 설계했습니다.
